# Finn Gleditsch - College Application Portfolio

## Videos:

- Videos 1, 2, and 3 are from the collaborative Unity game that I made in Game Design and Development class; the assets made by my teammates were the art for the water, the angler fish enemy, the seagull enemy, and the dungeon floors found in the first video. Every script and all other art assets, including sound design (using Online Sequencer), are of my own creation.

- Video 4's game clip came from an in-progress game I was making in Godot shortly after I finished my time in HelloWorld Coding Club; it served as my first independent game making experience using a professional game engine. I ended up abandoning the project before completion because switching from an old computer to a new one created technical complications in the original program. Art GIFs 1 and 2, as well as Art Images 5 and 6, were assets that I planned to add to the game before the project was shelved. The project file for this game is Project 2.

- Video 5 is from a game that, while not the most important thing in this portfolio, was my first true Godot game making experience. The assignment was to make our own version of Space Invaders. I created it during my time in HelloWorld Coding Club, with the instruction and help of the club's founder. (Because it was my first game project, the instructor advised me to just pull images and sounds directly from the internet.) The project file for this game is Project 1.

- Video 6 was made in Digital Art 2 using Adobe Animate; the assignment was to create a looped video that was reminiscent of old LoFi YouTube video backgrounds.

## Images and GIFs

- Art Images 1, 2, and 3 - Made with Adobe Illustrator. Part of my final project for my Digital Art 1. They are vector illustrations of an origami Gharial (a type of crocodilian), an origami Ruby-Throated Hummingbird, and an origami Spinosaurus. 
- Art Image 4 - Made using Piskel. The assignment was to create a pixel isometric room, so I made a room with lava in a swampy environment.
- Art Images 5 and 6 (and Art GIFs 1 and 2) - Made with Piskel. Were originally assets made for Project 2. Art GIFs 1 and 2 are of a creature with a bony head biting and running respectively. Art Image 5 was a compilation of creatures to add to the game including the skull creature in the GIFs. Art Image 6 was an incomplete front view of a humanoid in some kind of futuristic diving suit with an anchor on a chain attached to one of the arms.
- Art Image 7 - Made using Piskel. The assignment was to create a still life incorporating a skull; I made a Mosasaurus skull.
- Art Image 8 - Made using Adobe Photoshop. The assignment was to create a Photoshop drawing, with little to no restrictions on its parameters. I made a cyborg version of my teacher's cat Milton dreaming of fiery destruction (mostly because the idea seemed funny to me). The image it was drawn on was a real image of Milton.

## CODE SNIPPETS

- Code Snippets 1 and 2 were code files for Project 2. Code Snippet 1 is the script attached to the main scene, which serves the purpose of initializing the game and managing aspects that are not specific to any particular game object. Code Snippet 2 is the script attached to the "Player" game object. It handles animations, movement, and a specific future mechanic that changes the sprite of the player based on a variable that was intended to change as the game progresses. Changing the variable's value manually inside the code still changes the player's sprite; it's just that the game faced complications that stopped all development progress for the game (as mentioned in Video 4's description), leaving this as an unfinished feature.
- Code Snippets 3 and 4 were code files for the project I made in Game Design and Development as mentioned in Videos 1, 2, and 3. Code Snippet 3 is the script that handles everything regarding the "Player" game object for this project. It handles most of the functions for the player's methods of attack, the movement mechanics, the animations, and various other functions. Code Snippet 4 is the script for the head of the serpent and handles nearly every function of the serpent boss fight other than the scripts attached to game objects of each attack's components. (The boss fight's attack cycle is demonstrated in Video 3.)

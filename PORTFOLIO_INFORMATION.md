# Finn Gleditsch - College Application Portfolio

## Videos:

- Videos 1, 2, and 3 are from the collaborative Unity game that I made in my game design and development class; the assets made by my teammates were the art for the water, the angler fish enemy, the seagull enemy, and the dungeon floors found in the first video. Every script and all other art assets, including sound design, are of my own creation.

- Video 4's game clip came from an in-progress game I was making in Godot shortly after I finished my time in HelloWorld Coding Club; it served as my first independent game making experience using a professional game engine. I ended up abandoning the project before completion because switching from an old computer to a new one created technical complications in the original program. Art Images 5 and 6 and the two Sprite Animation GIFs were assets that I planned to add to the game before the project was shelved. The project file for this game is Project 2.

- Video 5 is from a game that, while not the most important thing in this portfolio, was my first true Godot game making experience. I created it during my time in HelloWorld Coding Club, with the instruction and help of the club's founder. (Because it was my first game project, the instructor advised me to just pull images and sounds directly from the internet.)

- Video 6 was made in a digital art class using Adobe Animate; the assignment was to create a looped video that was reminiscent of old LoFi YouTube video backgrounds.

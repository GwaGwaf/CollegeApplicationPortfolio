# Finn Gleditsch - College Portfolio

## Videos:
- The battle cats bounce video was a video I made for digital art in Adobe Animate with the assets made in Adobe Illustrator using images from the game The Battle Cats to help make the assets, the assignment was essentially a ball bouncing through scenes, otherwise you were basically free to customize it however you want.

- The videos of The Bioseer, the Dock Level Gameplay, and the Final Boss are from the collaborative game made in my game design and development class, the assets made by my teammates were the art for the water, the angler fish enemy, the seagull enemy, and the dungeon floors found in the Bioseer video. Every script and all other art assets in the videos are of my creation. Watching every video the full way through isn't required, so feel free to skim through them if you must. This applies to all videos in this portfolio.

- The Top-Down Game clip came from an in progress game I was making in Godot shortly after I had finished with HelloWorld Coding Club, it served as my first individual game making experience in a professional game engine. Although the project ended up being abandoned and left in its current state due to getting a new computer which brought complications to the project where for a while I thought the project was corrupted. The two unlabeled screenshots and the two GIFs were art assets planned to be added to the game before the project was shelved. The project file for the game is also attached as a .zip file, but looking into and downloading the .zip file isn't required for assessing the portfolio. this goes for the Space Invaders .zip as well.

- The Space Invaders video clip is from a Godot game made in HelloWorld Coding Club, which, while not the most important thing in this portfolio, was my first true Godot game project, made with the instruction and help of the person who runs HelloWorld Coding Club. Every image and sound in this project was simply from the internet.
